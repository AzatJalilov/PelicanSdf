Claude 5.x Pelican SDF benchmark

19 of 20 configurations attempted: four new Claude models × five effort levels, each shown next to its predecessor's July 2026 sweep. Every attempted max-effort run failed to return a response, so Fable 5.1 max was not run. Generation had a 60-minute limit per run from the Opus 5.5 max run onward. 12 renderable results; 13 catalog entries added. Each response used the unchanged canonical prompt, with no code repairs.

Generation time is complete Claude Code CLI elapsed time in seconds; runs were generated serially. Rendering uses three serial trials at 960 × 540; FPS is equivalent throughput from the median GPU frame time, not a visual-quality score. Blind visual scores remain null.

Validation standards differ between the two sweeps. The July predecessor runs were marked passed automatically when rendering produced no browser errors. Every new run was additionally audited against all canonical screenshots and its source, and visual defects such as clipped framing or bounding-volume shadow artifacts are recorded as unmet requirements. The comparison table therefore reports renderability only; read the findings column for the audit detail.
